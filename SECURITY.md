# Security Policy

## Supported Versions

Security updates are actively provided for the following versions of SQUARE:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of SQUARE seriously. If you discover a security vulnerability or potential issue regarding AI agent execution, API key handling, or vector DB exposure, please follow these steps:

1. **Do NOT open a public GitHub issue** for security vulnerabilities.
2. Email your findings directly to the repository maintainer at **shibani8144@gmail.com**.
3. Include detailed steps to reproduce the vulnerability, along with any relevant proof-of-concept logs or code.

### Vulnerability Response Process
- **Acknowledgment**: Within 48 hours.
- **Assessment**: We will investigate and confirm the impact.
- **Fix & Disclosure**: We will publish a patch release and notify the reporter prior to public disclosure.

Thank you for helping keep SQUARE safe and secure!
